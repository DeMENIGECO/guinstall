GUInstall è un installer da terminale che rende semplice installare e configurare ambienti desktop Linux, anche su WSL.

Inizia Vedi su GitHub

Perché GUInstall?

Tutto ciò che serve, senza configurazioni complicate.

⚡

Semplice

Una procedura guidata da terminale ti accompagna durante tutta l'installazione.

🖥️

GNOME + WSLg

Installa GNOME e avvialo in una finestra WSLg tramite Wayland e Mutter DevKit.

🧩

Espandibile

Il progetto è pensato per supportare più desktop environment e distribuzioni.

Installazione

Tre semplici passaggi.

1

Clona il repository

git clone https://github.com/DeMENIGECO/guinstall.git
2

Entra nella directory

cd guinstall
3

Avvia GUInstall

chmod +x installer.sh
./installer.sh

Stato del progetto

GUInstall è attualmente in sviluppo. Il supporto principale è dedicato a Debian/Ubuntu su WSL con GNOME tramite WSLg.
